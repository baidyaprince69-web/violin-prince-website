# Dandelions — Violin Prince

Complete, self-contained GitHub Pages source for the Dandelions violin-cover landing page by Prince Baidya (Violin Prince).

## Files
- `index.html` — page markup, metadata, social preview tags, and VideoObject structured data.
- `style.css` — responsive design, animated illumination, grain texture, levitating cards, layered shadows, and reduced-motion handling.
- `script.js` — responsive navigation, scroll reveals, YouTube IFrame API controls, and interactive mood-based song recommendations.
- `images/` — all six local image/SVG assets used by this page.

Google Fonts and YouTube remain external services. The embedded performance uses YouTube video ID `lTySNtT0rzs`.

Intended GitHub Pages route: https://baidyaprince69-web.github.io/violin-prince-website/dandelions/

Migration is staged on `staging/dandelions-github-migration`; `main` is unchanged.
