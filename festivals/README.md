# Diwali Listening Room

Static GitHub Pages version of the Violin Prince Diwali Festival Listening Room.

## Published path

`https://baidyaprince69-web.github.io/violin-prince-website/festivals/`

## Included in this repository

- `index.html`: full page markup, styles and interactions
- Shared site header and footer expanded into static HTML
- Animated radial rangoli artwork, including the SVG construction script
- Featured violin video, three additional music links, sweets section and two interactive games
- `../assets/diwali/violinist-playing-on-stage.jpg`: the uploaded violin performance portrait used as the opening background

## Texture image dependencies

The page retains its original high-resolution decorative texture photographs from the existing WebsitePublisher CDN: red woven fabric, aged paper, marigold petals, diya bokeh and the rangoli reference photo. They remain public CDN references in the page source; the portrait itself is stored in this repository. To make the page fully self-contained, those five texture images can be mirrored into `assets/diwali/` later and their URLs changed to local paths.

## Navigation and deployment

The page links back to the Violin Prince GitHub Pages project, its Covers Library, and the homepage music/request sections. It is designed for the repository subpath `/violin-prince-website/`, with the main homepage and existing song pages left unchanged.

The original WebsitePublisher page remains published separately.
