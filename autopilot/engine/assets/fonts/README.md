# Violin Prince video typography assets

The video renderer uses two typefaces from the Beautiful Web Type collection:

- **DM Serif Display** — editorial/display headlines.
- **DM Sans** — motion-graphic labels, supporting copy and word-synchronised captions.

Source catalogue: https://github.com/ubuwaits/beautiful-web-type

The font binaries are redistributed unchanged. Each font is separately licensed under the SIL Open Font License 1.1; the original notices are preserved in `DM-Serif-Display-OFL.txt` and `DM-Sans-OFL.txt`. The Beautiful Web Type website's MIT license does not replace the individual typeface licenses.

The renderer converts the WOFF2 files to local TTF working copies at runtime using fontTools. Generated copies are not committed.
